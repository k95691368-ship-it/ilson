# 코딩 영역 — 600자 설명

React 19 + Vite 프런트에 Cloudflare Pages Functions·D1(SQLite)·R2를 붙인 서버리스 풀스택입니다. 검증 로직을 isomorphic `shared/` 모듈 42개에 두어 브라우저와 Worker가 같은 함수를 실행하게 했습니다. 클라이언트와 서버 검증이 갈라질 수 없는 구조입니다.

새 테이블 생성이 막힌 제약에서는 `decision_log`의 `link_kind`를 discriminator로 삼아 26종 이벤트를 append-only 로그에 담고, 현재 상태는 리플레이로 계산합니다.

핵심은 포맷이 제각각인 채널 정산서 5종을 **브라우저에서 순수 JS로** 병합하는 결정론적 파이프라인입니다. CP949 인코딩 자동 판별, XLSX 헤더 오프셋 탐지, 파일명이 아닌 헤더 시그니처로 채널 식별, 미등록 SKU·합계행 격리, 체크섬 기반 멱등성을 구현했습니다. 시드 생성기가 입력과 정답을 함께 만들어 매 실행이 ground truth와 대조됩니다.

테스트 1,001개는 3층입니다. 순수 함수 단위, 스텁 D1/R2로 전 라우트 핸들러를 실제 호출하는 스모크, 그리고 소스를 정적 분석해 "화면이 읽는 키를 서버가 실제로 주는가"를 검증하는 배선 테스트. 예외를 던지지 않고 조용히 0이 되는 버그를 잡기 위한 층입니다. lint는 CI로 이관했습니다.
